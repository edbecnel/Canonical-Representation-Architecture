## Purpose

This domain holds **normative architecture specifications** and conformance requirements for the Canonical Representation Architecture.

Documents here define adoptable architecture, methodology, protocol behavior, and standards. They are authoritative for implementers and adopters.

## What Does Not Belong Here

- **Architectural discovery records** — non-normative historical documents (see [`docs/Architecture/`](../Architecture/README.md) or approved historical paths such as [`CRA-0000.md`](../../CRA-0000.md))
- Reference implementations — non-canonical; documented separately when present

## Identifier Convention

Normative specifications use the `CRA-NNNN` identifier series beginning at `CRA-0001`. Discovery record identifiers (e.g., `CRA-0000`) are a separate series and are never promoted to normative specifications without an explicit architectural decision.
