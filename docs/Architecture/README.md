## Purpose

This domain documents the architecture being **published** by the Canonical Representation Architecture program: discovery records, architectural decision records, watch items, principles, and reference models.

## Document Types

| Type | Normative? | Typical location |
|---|---|---|
| Architectural Discovery Record | No | `docs/Architecture/Discovery_Records/` or approved historical paths |
| Architecture Decision Record (ADR) | Decision record | `docs/Architecture/ADRs/` |
| Watch Item | No — until promoted | `docs/Architecture/Watch_Items/` |

Discovery records capture origin, motivation, and pre-specification exploration. They are **not** normative specifications. Normative architecture specifications belong in [`docs/Specifications/`](../Specifications/README.md).

In existing repositories, discovery records may reside at approved historical paths. See [`CRA-0000.md`](../../CRA-0000.md) at the repository root — the permanent historical foundation of this project. Subsequent discovery records belong in [`Discovery_Records/`](Discovery_Records/README.md).
